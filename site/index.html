DEVELOPER INTEGRATION

API Explorer

Example HTTP contracts for a locally running BrainLLM API. Availability depends on the compiled server version and runtime configuration.

API originUsed by the playground chat and connection test
POST/api/chat

Send a chat completion request using a messages array and token limit.

{
  "messages": [{ "role": "user", "content": "Explain attention" }],
  "max_tokens": 160
}
GET/api/status

Retrieve runtime status and metric fields available from the engine.

curl http://localhost:8080/api/status
GET/api/memory?query=learning

Search memory records using a URL-encoded query string.

curl "http://localhost:8080/api/memory?query=learning"
GET/api/airllm/config

Read runtime configuration and availability indicators for the optional AirLLM bridge.

curl http://localhost:8080/api/airllm/config
⚠

Browser security: HTTPS GitHub Pages cannot reliably call an HTTP-only local server from all browsers, and remote API access requires explicit CORS configuration. Do not expose an unauthenticated API or include private tokens in browser JavaScript.
